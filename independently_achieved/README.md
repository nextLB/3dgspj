


# 基于高斯溅射的无人机影像三维重构的算法实现方案    (2025.12.25)


## 第一阶段：数据准备与预处理

这是所有后续工作的基石，尤其对于无人机数据，需要特别处理。

1、输入数据：带POS（位置姿态）数据的无人机影像序列（如JPG+RAW）。理想情况下应有高重叠率（旁向>60%，航向>80%）。

2、关键处理

* 特征提取与匹配：使用COLMAP、OpenMVG等工具从图像中提取特征点（如SIFT），并进行匹配，建立稀疏的2D关联。
* 稀疏重建（SfM）：通过运动恢复结构技术，求解出每张照片的精确相机参数（包括旋转R、平移T构成的外参矩阵，以及焦距、主点等构成的内参矩阵K），并生成一个稀疏的3D点云。这个点云和相机参数是后续3D-GS初始化的关键。

3、输出: 一个包含相机参数文件（通常为cameras.json或images.txt）和稀疏点云文件（points3D.txt或.ply）的数据集。


## 第二阶段：初始化3D高斯场景

我们不能凭空开始优化，需要一个起点。

1、初始点云：直接将第一阶段SfM产生的稀疏点云作为初始的高斯中心位置（xyz）。

2、初始化属性：

* 颜色：从点云对应的图像像素中取样，作为初始颜色（或球谐系数初值）。
* 尺度与旋转：尺度初始化为一个经验性的小值（如对数尺度log(0.01)），旋转初始化为单位四元数。
* 不透明度：初始化为一个中等偏高的值（如经Sigmoid激活后约0.5）。

3、数据结构：将所有属性（xyz, color_features, scales, rotations, opacities）封装成可优化的张量（如在PyTorch中设置为requires_grad=True）。


## 第三阶段：核心迭代优化（训练循环）

这是最核心的步骤，对应图中第三阶段的大循环。每一次迭代都包含以下几个关键步骤：

步骤1：可微分渲染

对于每个训练视角（相机）：

* 投影：根据当前高斯参数和相机参数，利用 gsplat 的 project_gaussians 等函数，将3D高斯椭球投影到2D图像平面，计算其2D协方差、深度和像素覆盖范围。

* 排序与混合：对所有重叠在同一个像素上的2D高斯椭球按深度进行排序，并按照“从前到后”的顺序进行Alpha混合，最终合成该像素的颜色和透明度。gsplat.rasterization 函数封装了这一复杂过程。

步骤2：损失计算

计算当前渲染结果与真实无人机照片之间的差异，常用的损失函数组合为：

    Loss = λ1 * L1 + λ2 * D-SSIM

* L1损失：直接比较像素颜色差异，能保留锐利细节。
* D-SSIM损失（结构相似性指数的反）：更好地感知图像结构相似性，使重建更符合人类视觉。
* 通过 λ1 和 λ2 的权重（如 0.8 * L1 + 0.2 * (1 - SSIM)）来平衡两者。

步骤3：反向传播与参数更新

* 损失对所有的可优化高斯参数（位置、颜色、透明度、尺度、旋转）计算梯度。
* 使用优化器（如Adam）根据梯度更新这些参数。学习率调度策略非常关键，通常会对位置等几何参数和颜色等外观参数设置不同的学习率，并在训练过程中逐步衰减。

步骤4：自适应密度控制

这是3D-GS的精髓，让场景能够“生长”出足够的高斯来覆盖几何细节。

* 克隆（Clone）：对于在某个视角下面积（2D协方差）显著增大的高斯（意味着它覆盖了未被充分建模的区域），在它的位置附近克隆一个新高斯，并沿位置梯度方向轻微偏移，赋予其较小的初始尺度。
* 修剪（Prune）：定期移除不透明度持续低于阈值的高斯（它对渲染贡献极小），以及尺度变得异常大的高斯（通常是优化失败的离群点）。


## 第四阶段：输出与渲染

训练完成后，你需要一个可用的成果。

1、模型保存：将所有优化后的高斯参数（位置、球谐系数、不透明度、尺度、旋转）保存为标准格式，通常是 .ply 文件。gsplat 的 save_ply 函数可以直接完成。

2、高质量渲染

* 训练视角：可以直接使用训练好的模型和训练时的相机参数进行渲染。
* 新视角合成：对于任意新的相机位姿，只需调用相同的渲染管线，即可生成该视角下的图像。
* 视频生成：通过规划一条相机路径（如绕飞），逐帧渲染，即可生成平滑的飞行动画。
